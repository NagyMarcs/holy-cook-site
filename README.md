# Holy Cook — protótipo de site institucional

Protótipo navegável preparado para apresentação à Holy Cook.

## Visualização

O site é publicado pelo GitHub Pages. O endereço público aparece na seção **Deployments** do repositório depois da primeira publicação.

## Páginas

- Início
- A Holy Cook
- Cardápio
- Unidades
- Seja um franqueado

## Observações

- Este material é um protótipo de apresentação e não é o site oficial da Holy Cook.
- As informações de sabores, unidades e disponibilidade devem ser confirmadas pela marca antes de uma publicação oficial.
- O formulário de franquia funciona apenas como demonstração visual e não envia dados.
- As páginas estão configuradas para não aparecer em mecanismos de busca durante a fase de avaliação.
